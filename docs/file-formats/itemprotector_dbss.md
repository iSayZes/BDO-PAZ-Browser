# `itemprotector.dbss` Format

## Purpose

The items that protect an enhancement: one 5-byte row per item with its
protect type. On client 3483 the 13 rows are hammers (J's Hammer of
Loyalty and of Precision, Primordial, Obsidian, Ancient and Causality
Hammer) and crystals (Crystals of Origin, Crystals of Fate). The file is a
plain PABR table after decoding and has no `itemprotectoroffset.dbss`.

## Companion Files

None. The handler names each item with LOC type 0 from
`languagedata_*.loc` when it is loaded.

All multi-byte values are little-endian.

## Layout 1

### File Layout

| Offset              | Type           | Field        | Notes                                         |
| ------------------- | -------------- | ------------ | --------------------------------------------- |
| `+0x00`             | char[4]        | magic        | ASCII `PABR`                                  |
| `+0x04`             | u32            | row_count    | Number of items                               |
| `+0x08`             | Row[row_count] | rows         | See Row; byte-packed                          |
| `rows+0x00`         | String Table   | string_table | See String Table                              |
| `string_table+0x00` | u32            | table_start  | Offset of the string table, where `rows` ends |
| `string_table+0x04` | u32            | zero         | Always `0`                                    |

### Row (5 bytes)

| Offset  | Type | Field        | Notes                                                      |
| ------- | ---- | ------------ | ---------------------------------------------------------- |
| `+0x00` | u32  | item_key     | The protector item (LOC type 0 name); unique per file      |
| `+0x04` | u8   | protect_type | `0` or `1`; see Items and Open Questions                   |

### String Table (variable: 4 bytes + strings)

| Offset  | Type               | Field        | Notes                   |
| ------- | ------------------ | ------------ | ----------------------- |
| `+0x00` | u32                | string_count | Number of strings       |
| `+0x04` | pstr[string_count] | strings      | No field reads a string |

## Open Questions

### What `protect_type` Selects

On client 3483 every hammer for accessories stores `0` (Ancient Hammer and
its PEN and HEX versions, Causality Hammer) and every hammer for weapons
stores `1` (Primordial, Obsidian), so the value may pick the gear kind the
protector applies to. J's Hammer of Precision (`0`) and of Loyalty (`1`)
and the crystals have no gear list in their LOC text to test it against.
